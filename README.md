# TA-City-validation

## Description
Repo hosting the materials for the validation of the [TA City Model](https://github.com/alexandrepereiraarq/TI-City-Model).TA City is an agent-based model simulating population allocation at the metropolitan scale following scenarios (e.g., those from the (SSP framework)[https://en.wikipedia.org/wiki/Shared_Socioeconomic_Pathways]). It is an extension of the [TI City Model](https://github.com/skfagyemang/TI-City-Model) by Felix Agyemang.

## Goal
This repo provides access to the supporting material used in the validation process, including preview of results and webmaps.

## Usage
Access the data and play around with the webmaps.
